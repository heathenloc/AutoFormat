# AutoFormat 宣传页

独立的 GitHub Pages 静态网页，使用原生 HTML、CSS 和 JavaScript，无构建、后端或运行时依赖。

仓库已提供 `.github/workflows/pages.yml`，将完整 `site/`（含产品原型）发布到 GitHub Pages。首次启用与私有仓库套餐要求见 [发布说明](../docs/github-pages.md)。

当前采用现代学术出版物主题：所有页面导航为海军蓝 `#142238`，保留象牙白 `#F5F3EE` 字标；全站正文为象牙白底、黑色文字与版式图案。品牌青蓝色基础值为 `#22C7D6`，二级页面采用更沉稳的 `#2B707B`，用于模块链接、微调回路及优化指标。首页原型展示框为灰色 `#E2E2E2`、内部文字与图形为黑色；技术流程图与 AI 图表使用略深的象牙白 `#ECE9E2` 承托。共享主题配置在 `theme-editorial.css`，首页版式与背景图案由 `hero-editorial.css` 管理；首页与二级页面的浅色覆盖分别在最后加载的 `home-paper.css`、`secondary-paper.css`。正文保留无衬线字体，标题与导航字标使用本地衬线字体，无额外字体下载。旧暗色主题回滚标签为 `site-theme-baseline-2026-10-08`。

首页采用一屏出版物封面构图：象牙白底与极弱纸纹上，以低对比黑色在右侧局部叠放页边距框、基线、双栏段落、章节编号、页码与折角轮廓，左下角保留少量参考文献短条。SVG 横向透明蒙版让图案向文案区域逐渐消退，无满屏网格、真实文档截图或大图下载。段落在加载时只用一次 1800ms 的轻微归位动画，之后保持静止；减少动态效果时直接呈现最终状态。平板降低对比，手机仅保留边缘轮廓与底角短条。全部图形标为装饰且不接收鼠标、焦点或读屏；仅存在于 Hero，不延伸到展开模块及后续章节。点击首页按钮后，新展开的内容若在首屏下方，会平滑进入阅读区域，收起时仍返回对应按钮。

正文中的装饰分割线仅用于模块开头和结尾，统一与正文栏对齐；相邻模块共用边界线。移除标题前短线、格式清单行线、指标卡内部横线、原型内框和重复分隔。首页背景的局部细线构成抽象论文版式，三步处理流程使用动态连接线表达步骤顺序，完整流程图连接线、图例、交互控件边框及键盘焦点保持其功能用途。

二级页面采用“内容—页边距—象牙白纸张—纯白背景”的层次。纸张外侧仅保留每边 8–28px 白边，纸面内部另有随屏幕变化的留白，正文最大宽度为 1280px。纸张顶部紧接海军蓝导航，以 28px 高的横向标尺带跨过整张纸面；正文对应的标尺区域较浅，两端页边距略深，并加入类似 Word 的刻度、数字及缩进标记轮廓。标尺是背景装饰，不是可拖动控件。

四角短 L 形页边距标记位于标尺下方，内角与正文两侧边界对齐，纸面留白包围标记；不绘制连续的正文框线。标尺使用 1px、27%–32% 黑色线条并进一步减淡短刻度，页边距标记桌面不透明度为 22%、手机为 18%。手机减少刻度和数字密度。纸纹仅铺在纸面内部，底角位于实际纸张末端，不随滚动悬浮在内容上；全部装饰标为 `aria-hidden`，不接收指针或键盘焦点。强制颜色模式下隐藏纸纹和装饰。

网站图标使用用户提供的 AutoFormat A 字形／水滴图案，经内置 imagegen 换成海军蓝背景和象牙白图形。原尺寸图为 `assets/autoformat-logo.png`；浏览器使用 32／192px PNG 和多尺寸 ICO，移动端使用 180px 图标；Open Graph／Twitter 预览使用 512px `assets/autoformat-preview.png`。保留页眉的 AutoFormat 字标。编辑提示词见 `assets/autoformat-logo-edit.md`。页面资源以相对路径接入；分享平台元数据中的图片地址已配置为 `https://heathenloc.github.io/AutoFormat/assets/autoformat-preview.png`，更换域名时需同步更新四个页面。

网站按四个独立静态页面组织，各页顶部固定相同导航，当前页面以 `aria-current="page"` 标识。导航使用同目录相对链接，支持直接打开本地 HTML 和 GitHub Pages 仓库子路径。

- `index.html`：首页仅展示产品简介及其独立折叠的处理流程、格式能力，产品原型展示位移到简介下方。
- `workflow.html`：技术设计与产品 workflow，保留整体架构、三个详情弹窗和编辑前确认示例。
- `ai.html`：AI 选型与产品调优，保留模型策略与五项 Benchmark 对比。
- `business.html`：根据 `docs/commercial-feasibility.md` 第 5 节展示商业思考，包含四个商业主题、三项基准测算、月利润模型与验证路径；明确测算假设及尚待验证的性质。

每页拥有独立的中英文标题和分享描述，只加载所需的交互脚本。语言偏好跨页保存；共享 `main.js` 可在没有首页折叠模块或确认表单的页面运行。各页首段在固定导航下方留出阅读距离。

简介标题为“使用AI助手一键处理论文格式”。简介说明与 7 小时、16 分钟、首轮至少解决 92% 的数据文案之间固定换行，用放大且无下划线的数字突出显示。两个同样式按钮依次为“查看处理流程”和“了解排版能力”，默认透明填充、黑字黑边，悬停、键盘聚焦或展开时显示黑底象牙白字。两块内容默认折叠，各自独立展开与收起，可以同时打开；未点击的模块保持隐藏。“了解排版能力”直接展示全部 11 类格式。页面未接入文件上传或论文处理服务。

## 本地预览

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m http.server 4175 --bind 127.0.0.1 --directory site
```

打开 `http://127.0.0.1:4175`。也可直接打开 `index.html`；语言偏好在禁用存储的环境中仍可切换，但不会保存。

## GitHub Pages

将此目录的**内容**作为 Pages 发布根目录，保留 `assets/`、`.nojekyll`、CSS 和 JS。资源地址均为相对路径，支持用户主页和带仓库名前缀的项目主页。若放入独立仓库根目录，可在仓库 Settings → Pages 中选择对应分支及根目录；若使用本项目的 Actions 发布，则上传 `site/` 作为 Pages artifact。

本轮没有创建部署、修改仓库设置或上传 GitHub。

## 后续扩展

- 四页正文参考 `docs/autoformat-promotion-copy.md`，技术模块与确认示例的锚点保留在 `workflow.html` 内。
- 商业分析内容以 `docs/commercial-feasibility.md` 第 5 节为依据，排版位于 `business.css`，英文文案位于 `main.js`。三项测算分别为 11,000 元／月、约 1.05 元／任务及约 8,700 个任务／月，收益系数为 1.266；数字旁显示售价 29.9 元、付费率 8%、退款率 3% 等假设，避免将模型测算表现为实际业绩。页面仅展示文案，不新增收费或支付入口。
- 中文正文保存在各页 HTML，英文和界面文案位于 `main.js` 的 `messages`。元素用 `data-i18n` 和 `data-i18n-aria` 关联；初始化时读取当前页中文默认值，禁用脚本时仍能阅读。
- 独立的 `.site-background` 保留首页轻微纸纹；二级页面的外层为纯白，`main` 构成象牙白纸张。二级页面纸纹位于 `main::before` 的独立背景层，通过小尺寸内嵌 SVG 平铺；内容本身不应用滤镜。`.paper-decoration` 中的标尺横跨纸张，`.paper-margin-frame` 与 `.content-shell` 共用正文宽度，使四角与标尺缩进轮廓对齐。无需脚本或图片请求。首页 `.hero-artwork` 使用内联 SVG 与 `hero-editorial.css`，仅在封面局部绘制出版版式；无需 Canvas 或动画库。
- 产品简介使用一次性滚动入场动画；展开“处理流程”后，三个步骤以 0／200／400ms 的延迟从左到右淡入。步骤间两条细线随目标图标进入阅读区域，用 1200ms 从左向右绘制，第二段稍后衔接；手机纵向布局改为从上向下绘制，每次重新展开流程时重播。首页两个按钮分别控制独立的 420ms 高度／透明度动画，内容用 300ms 淡入；快速连续点击不会截断内容。再次点击对应首页按钮或该模块底部“收起”按钮，仅关闭该模块，焦点与阅读位置返回对应首页按钮。格式分类切换仍平滑衔接，再次点击当前分类可收起格式模块。减少动态效果时立即显示；折叠内容不进入键盘焦点与读屏顺序。刷新和锚点跳转均不自动展开模块，只有按钮点击才展开。禁用脚本时，流程与完整格式清单仍可阅读，无新增依赖。
- 技术设计的模块样式位于 `workflow.css`，完整流程图使用 `flowchart.css` 和 `flowchart.js`。流程图与文案文档的 Mermaid 对应，包含 12 个节点、13 条连线，展示编辑前确认与重新检查、下载分支，以及局部微调返回格式编辑的回路。节点使用 HTML，连线使用 SVG，并随窗口、字体与语言变化重新定位；窄屏自动改为纵向布局。连线在两端节点都到达视口下方约 82% 的阅读区域后，逐段延迟 240–440ms、用 1800ms 绘制；下方尚未浏览的连线保持等待。锚点跳转视为已浏览上方节点，不会留下缺线；动画仅播一次，减少动态效果时直接显示。
- 二级页面纸面覆盖统一流程图、数据卡片、弹窗与提示层的颜色。流程节点使用较浅的象牙白，正文和标签为黑色，主要连线为深灰、确认回路为黑色、微调回路为沉稳青蓝，箭头和图例与连线同步。AI 的优化前条形使用深灰，优化后条形、数值和改善幅度使用同一青蓝色，在两种象牙白底上的对比度均超过 4.5:1。强调文字使用原生字形和适度字重，移除墨色描边以避免重影；条形使用纯色，无阴影。提示层为象牙白底黑字。
- 三个模块的详细设计默认隐藏，不占正文空间。点击流程图中的模块名称，通过 `module-dialog.css` 和 `module-dialog.js` 打开原生 `dialog` 卡片；“查看确认示例”直接展示要求解析卡片里的示例。卡片以透视、缩放与位移动画从来源位置浮到前台，背景轻微压暗、模糊；系统要求减少动态效果时直接显示。支持关闭按钮、Esc 和点击外部关闭，关闭后焦点与页面位置返回原处。
- 向下滚轮关闭需在 700ms 间隔内累计至少 240px、至少两次事件，每次最多计入 120px；单次大滚动不关闭，上滚会重置累计。卡片内长内容先正常滚动阅读，到底后继续滚动才累计关闭距离；卡片外直接累计。模块详情交互需要 JavaScript，禁用时主页面与完整流程文字仍可阅读。
- 编辑前确认示例仅在浏览器本地演示：无默认答案，选择后需明确确认；支持暂时忽略、改选、重置和双语状态切换，不提交文件或调用后端。产品原型区域现已链接到 `prototype/index.html`，使用示例材料展示完整交互；原型不上传或实际处理论文。
- Benchmark 使用 `benchmark.css`、`benchmark.js` 和集中数据文件 `benchmark-data.js`，没有图表库或新增依赖。前三项质量指标在同一张卡片逐行展示，“优化后”横条在“优化前”上方；耗时与 Token 用量在两张卡片中使用竖向对比条形图，窄屏自动上下排列。每个数值与对应条形绑定，没有另外重复数字表或独立图表。
- 五项数据仅定义在 `benchmark-data.js` 的 `quality`／`efficiency` 数组中，包含 `before`、`after`、`direction`、格式、精度、中英名称及调优方法。F1 及效率、无依据候选指标采用相对变化，四舍五入到整数；范围准确率取百分点差，按产品要求将主卡徽标简写为“↑14%”，悬停说明保留“+14 个百分点”的准确单位。质量指标仅显示箭头及百分比，不另加提升／减少文字。UI 以 `direction` 判定正向改善，数值下降不自动视为退步。Token 用量包含单任务的输入、输出以及失败和重试消耗，当前暂用 8,400 → 4,000。
- 条形尺度也由数据控制：F1 为 0–1，范围准确率为 0–100%，无原文支持候选为 0–15%；效率指标按本项较大值归一化。悬停或键盘聚焦提示会显示该项范围、解释及调优方法，页面直接显示全部关键数值，手机阅读不依赖悬停。
- 对比条与数字首次进入视野时用 850ms ease-out 同步增长，质量指标改变宽度，效率指标从底部改变高度；After 延迟 150ms，改善幅度最后淡入。后续滚动不重播；减少动态效果或不支持 IntersectionObserver 时直接显示最终值。屏幕阅读器读取最终数值，不播报逐帧计数。
- 后续替换真实 Benchmark 只需修改 `benchmark-data.js` 中的数据及中英 `methodology` 来源文案。数值仍为待替换的占位配置；页面按产品要求移除演示徽标，来源显示“数据来源于20份内部测试结果”。来源说明会随语言切换更新。
- 窄屏自动使用菜单按钮；支持键盘焦点、Escape 关闭和屏幕阅读器导航。语言偏好保存为 `autoformat-site-language`，首次访问会继承旧 `easyformat-site-language` 的有效偏好。
