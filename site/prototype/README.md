# AutoFormat HTML 交互原型

`index.html` 是无外部依赖的单文件交互原型，CSS 与 JavaScript 均内嵌，可直接打开或托管在 GitHub Pages。使用内置虚构 Brief 与论文示例，不读取所选文件正文、不上传文件、不调用真实解析／排版服务。

## 体验路径

顶部导航沿用海军蓝，页面以纯白为底色。「论文空间」下拉菜单集中提供新建任务、格式要求、预览与微调、版本历史、修改报告和重新开始；右侧依次为体验指南、返回产品介绍和访客入口。菜单支持点击外部关闭、Esc 关闭，以及方向键导航。

从宣传页点击「打开交互原型」时，通过 `#upload` 明确进入「新建任务」页；已有演示进度与版本历史仍然保留，可从「论文空间」继续查看。

1. 点击「自动填充文件」，再「解析格式要求」。
2. 先处理一级标题对齐冲突，再确认模板页面版式。没有默认答案；点选即确认，可直接点击另一选项改选；也可明确暂时忽略。未回答时不能点击「开始修改」；全部选择或明确忽略后，点击该按钮生成初稿。左侧「查看全部修改项」展示待应用、待确认、忽略与待复核项目。
3. 生成 V1 后选中预览文字，输入「这里改成左对齐」等需求，检查实际作用范围。与已确认规则冲突时选择保留原规则、本处例外或更新同类规则。
4. 每次实际编辑生成新版本；在历史版本中「返回此版本继续修改」会从所选父版本新建分支，保留既有后代。
5. 下载的 DOCX 是根据当前版本状态生成的**内置示例论文**，不是对用户所选文件的实际编辑结果。报告与预览也只描述示例。报告页可通过「下载报告」右侧的「返回预览」回到同一版本。

## 导入墨刀

优先在墨刀工作区的「HTML 转原型」中粘贴 `index.html` 的完整源码，或使用账号界面提供的 HTML 文件导入功能。官方说明：https://modao.cc/feature/ai-api.html 。

如转换器只识别首屏，可使用 `modao-import.html`（全部关键画板展开）或 `pages/` 中逐页自包含的 HTML。后者保留可编辑的语义化文本、容器、按钮与表单结构；导入后按下面的清单补齐连接与状态。HTML 转换对脚本、页面拆分及交互的保留程度取决于墨刀实际转换结果，本项目没有对墨刀账号执行导入。

| 画板 | 主要入口／操作 | 目标 |
| --- | --- | --- |
| 01 新建任务 | 自动填充文件、解析要求 | 02 解析进度 |
| 02 解析进度 | 解析完成 | 03 编辑前确认 |
| 03 编辑前确认 | 逐项选择／明确忽略、开始修改 | 04 预览与微调 |
| 04 预览与微调 | 选择文字、检查修改 | 05 冲突处理 |
| 05 冲突处理 | 明确选择处理策略、生成新版本 | 04 预览与微调 |
| 06 版本历史 | 查看、返回此版本继续修改 | 04 预览与微调 |
| 07 修改报告 | 筛选结果、下载报告、返回预览 | 对应版本报告／04 预览与微调 |
| 08 解析失败 | 重试解析 | 02 解析进度 |
| 09 论文空间下拉菜单 | 展开／关闭菜单、选择工作空间入口 | 对应工作页面 |

第 09 张画板展示菜单展开状态。导入墨刀后，将「论文空间」按钮连接至该状态，并为菜单入口、点击外部关闭及重新开始确认补齐交互。逐页 HTML 中也提供菜单展开／关闭的静态页面链接；完整浏览器交互仍以 `index.html` 为准。

导入验收：全部页面和主要文字可编辑；顶部导航及下拉菜单入口齐全；两个确认项无默认答案；未作答不能开始编辑；点选与改选即时生效；取消冲突不会创建版本；局部例外只继承到后代；历史分支保留原后代；下载与所选版本对应；返回、关闭、重试均有目标。

## GitHub Pages

将宣传页 `site/` 的全部内容一起发布，保持 `prototype/` 子目录。宣传页入口使用 `./prototype/index.html#upload`；原型内返回宣传页使用 `../index.html`，兼容带仓库前缀的项目站点。无需 Node、打包、API 密钥或后端。

原型只在浏览器本地保存演示进度；「重新开始」会先确认，再清除本原型的演示记录。无法使用本地存储时仍可体验当前会话。

## 维护和验证

源文件是 `index.html`。在项目根目录启动静态服务器后，运行 `scripts/verify_prototype.mjs` 进行流程验收并生成导入画板；截图和测试下载存放于忽略目录 `runtime/prototype-qa/`。运行方式见脚本文件头注释。

本原型表现已确认的产品流程，不代表真实 DOCX 引擎、PDF 渲染器或 AI 解析准确率验收。预览是可选文字的 HTML 示例，下载 DOCX 的分页可能与预览不同；目录和页码仍标为待人工复核。
