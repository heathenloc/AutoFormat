# 第三项：Brief 自带模板版式读取

日期：2026-10-02。已完成 DOCX 逻辑版式读取、报告契约、明文对照和 AutoFormat 入口接入。用户已确认继续使用现有模板，本轮无需补充材料。

## 目前可用

`BriefParserService.parse_academic` 输出 `AcademicParseBundle/1.4`：

| 字段 | 用途 |
| --- | --- |
| `format_ruleset` | 明文格式规则，保留 `academic-format-rule-set/1.3` |
| `source_review` | 来源识别和格式属性漏提复核，保留 `academic-source-review/1.0` |
| `template_layout` | 独立只读观察，使用 `academic-template-layout/1.0` |

读取器使用安全检查后传入文字解析流程的同一份不可变 Brief 字节。只读 Brief，不从论文原稿推导学校要求，不打开 Word、不抓取外部关系目标、不改写输入。非 DOCX 来源仍提取明文，并报告模板版式读取不可用。

| 对象 | 已读取的属性及依据 |
| --- | --- |
| 文档节 | 页面宽高、A4 判定、明示方向、四边边距、装订线、页眉页脚距离、明示分栏、文字方向、页码格式与起始值 |
| 段落 | 对齐、段前段后、倍数／固定／最小行距、首行／悬挂／左右缩进、与下段同页、段内不分页、段前分页、网格对齐 |
| 文字 | 中西文字体槽、字号、粗体、斜体；分别保留中文、Latin 等字符范围，避免把英文字体要求套给中文 |
| 样式和主题 | 文档默认值、段落和字符样式、`basedOn`、表格基础样式、直接属性、可解析的主题字体；记录每层来源 |
| 表格 | 表级与单元格边框；简单完整网格可归一为全框线／无边框；重复表头标记与后续行的字体、段落候选属性 |
| 页眉页脚 | 每节的引用、继承、默认／首页／偶数页变体、段落和字体属性、PAGE 字段指令的存在；不把示例学校名称或论文题目抽成规则 |
| 脚注尾注 | 普通注释段落和文字属性；分隔符不作为正文注释 |
| 区域角色 | 摘要、目录及目录级别、正文标题、正文、参考文献、致谢、附录等候选；真实标题样式结束目录／摘要区域 |

所有观察值固定为 `source_kind=template_observation`、`status=pending_confirmation`。位置包含 DOCX 部件、XML XPath、节／段／表／行／列／run 索引；每项还保留文件 SHA-256、属性层、样式 ID、原始属性和 XML 节点哈希。注释编号与页眉变体可从 XPath／角色依据核对。逻辑行列指 XML 单元格顺序，不冒充合并后视觉网格坐标。

## 明文对照与后续流程

按格式类别、语义角色、属性、字符范围和单位聚合实际观察值，依次报告：

1. 明文与模板版式不同；保留模板位置和对应明文规则 ID。
2. 明文缺值、条件或冲突尚待确定；不得借模板沿用绕过待定项。
3. 同类模板对象版式不一致，或继承／结构无法确定。
4. 明文未提及且观察值一致；供 V1 后决定是否沿用模板。
5. 明文与模板一致；执行依据仍来自明文规则。

明示统一边距与四边观察值对照；cm／pt 做单位转换并允许 twips 的小量舍入误差。字符专用规则优先用于该字符范围。说明段落、隐藏文字、修订对象和未确定来源的观察不会进入模板沿用分组。

报告 Markdown 和 V1 修改报告已包含这些项目。用户首次仍只上传 Brief 与论文原稿。模板确认不是生成 V1 的前置步骤。本轮提供问题数据及顺序，后续的类别确认界面、决策编译和更广的格式编辑仍待开发；当前 V1 发布器仍是明确标注的原稿副本基线。

AutoFormat 上传入口和重新读取任务时，会从实际存储的 Brief 重算模板报告；改变观察值或分组，即使伪造后的 Bundle 能通过数据模型校验，也会被拒绝。独立 `AcademicParseBundle` 校验可检查来源绑定和分组重算；离开持有 Brief 字节的可信入口，它无法单凭 JSON 证明某个 XML 属性真实存在。

## 明确的覆盖边界

- 读取的是 OOXML 声明的逻辑属性；不推算 Word 最终分页、实际字体回退、视觉页面坐标或图像内容。
- 模板和区域判断属于候选识别，可能把说明文件中提到的模板章节识别成候选；保留检测依据，最终适用范围仍需核对。
- 未声明的宿主默认值不补造。循环／缺失样式、多个默认样式、无法确定的主题、自动间距、重叠缩进表示及多层粗体／斜体 toggle 等保守留为未确定。
- 条件表格样式、单元格合并及边框覆盖尚未构建完整视觉边缘模型；三线表保留实际边框观察，暂不自动判定。第一行无重复表头标记时不强行认作表头。
- 页眉页脚变体只记录已定义的逻辑内容；尚不判定某变体最终在哪一页启用。PAGE 字段仅识别指令存在，尚不完整解释字段开关及重新计算页码。
- 嵌套表格、内容控件、文本框、绘图／嵌入对象和 OCR 暂未完整读取，输出诊断；修订及隐藏内容不作为沿用依据。
- 每个来源最多 6000 项观察，截断有明确诊断；整个入口仍受现有文件和 Bundle 大小限制。
- 字数、词数、篇幅及具体内容要求继续排除；版式数据中的分栏数、目录级别和字符缩进属于格式。

## 后续扩展位置

版式读取放在 `adapters/template_layout.py`，独立数据契约放在 `domain/template_layout.py`，对照和渲染放在 `compilers/template_layout.py`。新增复杂对象可扩展观察属性与解析器，契约含义改变时发布新版本，并保留旧版重算实现。通用 IR 与既有格式规则语义本轮保持独立；历史 1.0–1.3 Bundle 仍可读取。
